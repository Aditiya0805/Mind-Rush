    # Mind Rush 🧠

    **Game Edukasi Tower Defense Seru!** Jawab pertanyaan untuk melawan gelombang zombie dan lindungi Brainy si maskot otak!

    ![Mind Rush Screenshot](screenshot.png)

    ## Fitur Utama

    - **3 Mode Edukasi**: Pilih tingkat kesulitan berdasarkan usia (Anak, Pra-remaja, Remaja)
    - **18 Kategori Soal**: Mencakup sains, matematika, geografi, sejarah, pengetahuan umum, dan banyak lagi
    - **Brainy si Maskot Otak**: Karakter maskot yang lucu menjadi target zombie
    - **Tower Defense Mechanics**: Tembak zombie yang mendekat dengan jawaban benar
    - **Combo System**: Rantai jawaban benar untuk serangan spesial (TURBO, Area Attack, Brain Blast!)
    - **Power-ups**: Gunakan 5 power-up strategis untuk membantu bertahan
    - **3 Nyawa & Shield System**: Lindungi Brainy dari serangan zombie
    - **Boss Battles**: Hadapi bos zombie di akhir setiap world
    - **Multi-language**: Onderwyss & zombie dialog menggunakan bahasa Indonesia
    - **Responsive Design**: Bermain di desktop atau mobile dengan tampilan optimal
    - **High Score Tracking**: Pantau skor tertinggi di setiap kategori
    - **Audio & Particles**: Efek suara dan partikel seru untuk setiap aksi

    ## Cara Bermain

    1. **Pilih Kategori Usia**: Cocokkan tingkat kesulitan dengan usia pemain
    2. **Jawab Pertanyaan**: Pilih jawaban yang benar sebelum zombie mencapai Brainy
    3. **Strategi**: Pilih power-up pada saat yang tepat
    4. **Bertahan**: Lawan gelombang zombie yang semakin cepat dan kuat
    5. **Raih Bintang**: Dapatkan bintang berdasarkan kecepatan menjawab dan akurasi

    ### Mekanisme Serangan

    - **Jawaban Benar**: Tembak zombie terdekat
    - **TURBO**: Benar <5 detik → damage x2
    - **Combo x3**: Serang satu jalur secara berurutan
    - **Brain Blast!**: Combo x5 → serang semua jalur
    - **Jawaban Salah/Waktu Habis**: Nyawa berkurang 1 ❤️

    ### Power-up

    - **Freeze (F)**: Bekukan semua zombie selama 5 detik
    - **50:50 (H)**: Hilangkan 2 jawaban salah
    - **Skip (S)**: Lewati soal saat ini
    - **Shield (L)**: Lindungi dari 1 serangan zombie

    ## Instalasi & Setup

    1. Clone repository:
    ```bash
    git clone <repository-url>
    ```

    2. Buka file `index.html` di browser:
    ```bash
    open index.html
    ```

    ## Teknologi yang Digunakan

    - **HTML5 Canvas**: Untuk rendering grafis dan animasi
    - **JavaScript ES6**: Logika game dan manajemen state
    - **CSS3**: Styling dan animasi UI
    - **Web Audio API**: Efek suara game
